### 🇷🇺 Русский

Легковесный и производительный агент для мониторинга системных ресурсов Linux-серверов. Разработан на языке Go без использования тяжелых сторонних библиотек (сбор метрик происходит напрямую через парсинг подсистемы /proc и низкоуровневые системные вызовы). Является частью экосистемы HostPulse CRM. 

### ✨ Особенности

* ⚡ **Минимальное потребление ресурсов**: благодаря компиляции в чистый бинарный код, агент потребляет до 15-20 МБ оперативной памяти и практически не нагружает CPU.
* 📦 **Мгновенное развертывание**: поставляется в виде изолированного Docker-контейнера на базе Alpine Linux (размер образа ~20 МБ).
* 🔒 **Безопасность и прозрачность**: код полностью открыт. Агент не имеет доступа к вашим персональным данным или файлам, собирая только телеметрию производительности.

### 📊 Собираемые метрики

Агент отправляет данные в CRM каждые 10 секунд: 

1. **CPU Usage (%)** — общая загрузка процессора (усредненная по всем ядрам за дельту времени).
2. **RAM Usage (%)** — процент использования оперативной памяти.
3. **Disk Space Usage (%)** — процент заполнения корневого раздела (/).

### 🛠 Быстрый запуск

Рекомендуемый способ запуска — использование официального Docker-образа, автоматически собранного через GitHub Actions. 

Вам не нужно клонировать репозиторий, достаточно выполнить одну команду на вашем целевом сервере (все переменные генерируются вашим Telegram-ботом CRM): 

bash

docker rm -f metrics-agent || true && docker run -d \
--name metrics-agent \
--restart unless-stopped \
-v /proc:/proc:ro \
-e HOSTPULSE_METRICS_URL="https://your-crm-domain.com/api/v1/metrics/" \
-e HOSTPULSE_TOKEN="your-server-uuid-token" \
-e HOSTPULSE_SECRET="your-secure-password" \
ghcr.io/HOST-PULSE/hostpulse-metrics-agent:latest


**Важно:** Монтирование ключа -v /proc:/proc:ro в режиме "только чтение" строго обязательно. Оно позволяет изолированному Go-приложению внутри контейнера видеть реальные показатели процессора и памяти хост-машины. 

### ⚙️ Переменные окружения

* HOSTPULSE_METRICS_URL — Прямой API эндпоинт вашей CRM для приема JSON-пакетов метрик.
* HOSTPULSE_TOKEN — Уникальный UUID идентификатор сервера, сгенерированный в CRM.
* HOSTPULSE_SECRET — Секретный пароль для валидации удаленных команд (не сохраняется в CRM).

### 🇬🇧 English

A lightweight and high-performance agent for monitoring Linux server system resources. Developed in Go without heavy third-party dependencies (metrics are collected directly by parsing the /proc subsystem and using low-level system calls). It is a native part of the HostPulse CRM ecosystem. 

### ✨ Features

* ⚡ **Ultra-low Resource Footprint**: Due to pure Go compilation, the agent consumes less than 15-20 MB of RAM and has a near-zero CPU overhead.
* 📦 **Instant Deployment**: Packaged as an isolated Docker container based on Alpine Linux (image size is ~20 MB).
* 🔒 **Secure & Transparent**: Fully open-source. The agent has no access to your personal data or files, collecting only performance telemetry.

### 📊 Collected Metrics

The agent pushes telemetry to the CRM every 10 seconds: 

1. **CPU Usage (%)** — Total CPU load (averaged across all cores over a time delta).
2. **RAM Usage (%)** — Percentage of used RAM.
3. **Disk Space Usage (%)** — Percentage of root partition (/) disk usage.

### 🛠 Quick Start

The recommended installation method is using the official Docker image automatically built via GitHub Actions. 

No need to clone the repository; just execute a single command on your target server (variables are generated by your Telegram CRM Bot): 

bash

docker rm -f metrics-agent || true && docker run -d \
--name metrics-agent \
--restart unless-stopped \
-v /proc:/proc:ro \
-e HOSTPULSE_METRICS_URL="https://your-crm-domain.com/api/v1/metrics/" \
-e HOSTPULSE_TOKEN="your-server-uuid-token" \
-e HOSTPULSE_SECRET="your-secure-password" \
ghcr.io/HOST-PULSE/hostpulse-metrics-agent:latest


**Important:** Mounting -v /proc:/proc:ro in read-only mode is strictly required. It allows the isolated Go application inside the container to read the host machine's actual CPU and memory statistics. 

### ⚙️ Environment Variables

* HOSTPULSE_METRICS_URL — Direct API endpoint of your CRM to accept JSON metric payloads.
* HOSTPULSE_TOKEN — Unique UUID server identifier generated by the CRM.
* HOSTPULSE_SECRET — Secret password for validating remote commands (not stored in the CRM).

### 🇰🇿 Қазақша

Linux серверлерінің жүйелік ресурстарын бақылауға арналған жеңіл және өнімділігі жоғары агент. Ауыр сыртқы кітапханаларсыз Go тілінде жасалған (метрикалар тікелей /proc ішкі жүйесін талдау және төмен деңгейлі жүйелік шақырулар арқылы жиналады). HostPulse CRM экожүйесінің бөлігі болып табылады. 

### ✨ Ерекшеліктері

* ⚡ **Ресурстарды минималды тұтыну**: таза Go кодина компиляциялануының арқасында агент 15-20 МБ-қа дейін жедел жадты тұтынады және CPU-ға дерлік жүктеме түсірмейді.
* 📦 **Қос нүктелі жылдам орнату**: Alpine Linux негізіндегі оқшауланған Docker контейнері түрінде жеткізіледі (образ өлшемі ~20 МБ).
* 🔒 **Қауіпсіздік пен ашықтық**: код толықтай ашық. Агенттің сіздің жеке деректеріңізге немесе файлдарыңызға қолжетімділігі жоқ, ол тек өнімділік телеметриясын жинайды.

### 📊 Жиналатын метрикалар

Агент әр 10 секунд сайын CRM-ге деректерді жіберіп отырады: 

1. **CPU Usage (%)** — процессордың жалпы жүктемесі (уақыт дельтасы бойынша барлық ядролардың орташа мәні).
2. **RAM Usage (%)** — жедел жадты пайдалану пайызы.
3. **Disk Space Usage (%)** — түбірлік бөлімнің (/) толу пайызы.

### 🛠 Жылдам іске қосу

Репозиторийді клондаудың қажеті жоқ, мақсатты серверде бір команданы орындау жеткілікті (барлық айнымалылар сіздің Telegram CRM ботыңыз арқылы жасалады): 

bash

docker rm -f metrics-agent || true && docker run -d \
--name metrics-agent \
--restart unless-stopped \
-v /proc:/proc:ro \
-e HOSTPULSE_METRICS_URL="https://your-crm-domain.com/api/v1/metrics/" \

-e HOSTPULSE_SECRET="your-secure-password" \
